PMC-Eight browser tools

Talk to the mount over USB straight from the browser. No install, no Python, no Terminal.

Read-only

Identify my mount

Plug in USB, click once. The mount reports its model, firmware version and which Wi-Fi module is fitted — so you never have to work that out yourself.

Can write firmware

Firmware loader

Loads Propeller (P1) mount firmware over USB. Staged: handshake and RAM loads are safe or reversible; the EEPROM write is not.

Before you start

  • Use desktop Chrome, Edge or Opera. Firefox, Safari, iOS and Android Chrome have no Web Serial API.
  • Close UFCT, the PMC8 Dashboard and any other serial tool first — Windows will not share the COM port.
  • Power the mount and use the data USB cable, not a charge-only one.
  • This is the Propeller, the mount's brain. The Wi-Fi module is a separate processor updated a different way.

What actually happens

The page and firmware image are downloaded once over HTTPS. After that the whole session is local — browser to USB driver to mount. You could unplug the network mid-flash and it would still finish.
