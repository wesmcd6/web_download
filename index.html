Talk to the mount over USB or Wi-Fi, straight from the browser. Open a section to use it.

Connect
not connected

USB resets the mount when the port opens — Windows asserts DTR while configuring it, and DTR is the Propeller's reset line. Nothing in the browser can prevent that, so the first 15–20 seconds of "no reply yet" are the mount rebooting. It happens once; the port then stays open. Wi-Fi does not reset the mount, but cannot reach the ESP firmware version or load firmware.

Firmware upload Permanent

Writes a new Propeller (P1) image to the mount's EEPROM and runs it, then reads the version back to prove it took. This is the mount brain, not the Wi-Fi module. USB only.

No image chosen.
Network

Join the mount's Wi-Fi module to your home network, or read the address it already has. USB only — Wi-Fi cannot configure Wi-Fi, it would cut the link carrying the request.

Restore RN131 Permanent

Writes the Explore Scientific factory configuration back to an RN-131 Wi-Fi module and reboots it — the same sequence UFCT sends. Use it when the module's settings have been lost or changed and it no longer joins a network. USB only, and only for RN-131: ESP8266 and ESP32 modules are configured a completely different way.

It restores the soft-AP at 192.168.47.1, device id and passphrase PMC-Eight, and port 54372. Any home-network settings on the module are replaced.

Disconnect anything else talking to the mount over Wi-Fi first — an app or PWA polling the mount shares the same Wi-Fi module, and its traffic knocks the module out of command mode partway through.
