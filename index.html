3 · Update the mount

Writes the image to the mount's EEPROM and runs it, then reads the version back to prove it took. Do not disconnect during the burn.

Advanced — diagnostics and reset-line options

Only needed if an update fails. The defaults match the loader already proven on this hardware.

Reset and listen prints the boot splash and reads the version — writes nothing. Handshake only proves the reset wiring and the boot ROM are reachable — writes nothing. Load to RAM only runs the image from RAM without touching EEPROM, so a power cycle undoes it.
