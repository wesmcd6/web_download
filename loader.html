PMC-8 firmware loader

Loads Propeller (P1) mount firmware over USB from the browser. This is the mount brain, not the Wi-Fi module.

not connected
Reset line options — only touch these if phase 1 fails

Defaults match the loader that is already proven on this hardware: reset is on DTR, asserted for 25 ms, then 90 ms to settle.

Writes nothing

2 · Phase 0 — reset and listen

Pulses reset and prints whatever the mount says. Normal firmware emits a long ASCII boot splash including Mount Type: P9 = n and the Wi-Fi module name, so silence here is a symptom, not a pass. Allow several seconds — the splash itself waits on the Wi-Fi module.

Writes nothing

3 · Phase 1 — handshake and read version

The real milestone. Proves the reset wiring, the line polarity, the LFSR and that the boot ROM's timing window is reachable from a browser. A P1 answers version 1. Nothing is stored on the mount.

No image chosen.
Reversible

5 · Phase 2 — load to RAM

Loads and runs from RAM. A power cycle restores the existing firmware, which makes this the safe way to exercise the whole bulk-transfer path against real hardware.

Permanent

6 · Phase 3 — write EEPROM

Overwrites the mount's firmware. Do this only once phases 1 and 2 are boringly repeatable, with a known-good image in hand and a desktop loader standing by for recovery. Do not disconnect during the burn.
