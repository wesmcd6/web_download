Identify my PMC-Eight

Plug in the USB cable, click once, and the mount tells you what it is — model, firmware version, and which Wi-Fi module is fitted.  ·  ← Firmware loader

Read-only

This page sends exactly two commands, ESGv! and ESGi!. Both are pure reads. Nothing is written, no setting is changed and no motor moves.

Opening the port can make the mount reboot on its own, which takes 15–20 seconds. If that happens this just keeps asking until it answers — leave it running.

Also read Fast Server / Envision status (not read-only)

The Dashboard reads this with ESGe!. Despite looking like a getter it is not side-effect free: if the Wi-Fi module answers ERROR, the firmware writes ENVISION_BOOT = 0 to EEPROM and commits. It can also block for a couple of seconds waiting on the module. Off by default for that reason; skipped automatically on RN-131, which is never Envision-capable.

Also read the Wi-Fi module's own version (changes mode)

Gets the module's AT+GMR output — AT version, SDK version and the bin version such as ES2.2.0(WROOM-32). Reaching it means ESPw42!, which hands the USB line to the module and blocks the mount's command interpreter until passthrough ends. The exit (###) is always sent, even if the module never answers, and ES commands are then re-tested before reporting success. Skipped on RN-131, which does not use AT commands.
