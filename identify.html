PMC-Eight settings

Plug in the USB cable, click once, and the mount tells you what it is — model, both firmware versions, and every stored setting. Then change them.  ·  ← Firmware loader

Reading changes nothing

Reads the mount's configuration and both firmware versions — the mount's own and the Wi-Fi module's. Reading changes nothing and moves no motor.

Once read, the settings become editable. Saving writes them to the mount's EEPROM, and asks first.

Opening the USB port resets the mount — Windows asserts DTR while configuring the port and DTR is the Propeller's reset line. Nothing in the browser can prevent it. The connection then stays open for the whole session, so it happens once, not on every read. Wi-Fi does not reset the mount at all, so use it if a reset is unwelcome.
